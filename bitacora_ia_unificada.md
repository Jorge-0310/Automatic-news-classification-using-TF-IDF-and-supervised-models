## Reflexión final

La matriz muestra que la inteligencia artificial se utilizó como apoyo para estructurar documentos, analizar alternativas y mejorar la presentación del proyecto, pero las decisiones finales se tomaron a partir de verificaciones técnicas y criterios del equipo. El caso más importante fue la evaluación experimental: la línea base histórica había utilizado el conjunto de prueba antes de definir la comparación. Utilizar ese resultado para escoger configuraciones habría introducido una ventaja metodológica indebida. Por eso se adoptó un flujo que selecciona el modelo con una partición de validación y reserva el conjunto de prueba para la medición final.

La interacción con las herramientas también permitió detectar y corregir problemas concretos. Se corrigió un error del extractor de errores que podía duplicar índices, se fijó una versión compatible de `pyarrow`, se separaron las funciones de inferencia de las de entrenamiento y se ajustó el tiempo del smoke test para reflejar el tiempo real de carga del modelo. Estas decisiones no se aceptaron únicamente por haber sido propuestas por una herramienta: se comprobaron mediante compilación, pruebas unitarias, `pip check`, entrenamiento completo, inferencia y pruebas de integración del frontend.

Otro aprendizaje fue la importancia de proteger los datos y limitar las afirmaciones del sistema. Los textos de AG News no se publicaron en los resúmenes del dashboard, las hipótesis automáticas sobre errores se trataron como apoyo y no como explicaciones causales demostradas, y la interfaz comunica que las probabilidades no verifican la veracidad de una noticia. Del mismo modo, las cifras de costo computacional y huella de carbono se presentan como estimaciones del experimento de entrenamiento, no como consumo exacto de cada visita.

En conjunto, la IA aceleró tareas de documentación, implementación y diseño, pero la calidad del resultado dependió de mantener una separación clara entre sugerencia y evidencia. El equipo conservó las propuestas que podían explicarse y reproducirse, modificó las que necesitaban adaptación y descartó las que podían comprometer la validez experimental, la privacidad del corpus o la interpretación responsable de los resultados.
