# Cuaderno exploratorio

`exploracion.ipynb` permite revisar distribución de clases, longitudes
agregadas de textos de entrenamiento y métricas ya calculadas en
`experiments/model_comparison.csv`. Se ejecuta desde la raíz del repositorio
tras instalar `requirements.txt`. Si no hay un lector de notebooks, los
scripts `src/train.py` y `src/error_analysis.py` siguen siendo el flujo
principal. No guarda ni publica texto de noticias en salidas del cuaderno.
